# Brand coverage checklist

Use this at handover to confirm that the guide covers every branding requirement. Each line maps to a chapter.

## Identity
- [ ] Brand foundations: mission, vision, values, positioning, audiences, personality, tagline, boilerplate (02)
- [ ] Logo: type, anatomy, versions, clear space, minimum sizes, placement, backgrounds, misuse, formats, alt text (03)
- [ ] Colour: roles, values (HEX/RGB/HSL/OKLCH/CMYK/Pantone to verify), proportions, scales, state colours, approved pairings, CVD, dark mode, print (04)
- [ ] Typography: families, licences, fallbacks and substitutes, scale, hierarchy, readability rules, languages (05)

## Visual language
- [ ] Layout, grid, spacing, radius, elevation, reflow (06)
- [ ] Iconography and accessible naming (07)
- [ ] Photography, illustration, representation, rights, alt text, AI imagery policy (08)
- [ ] Data visualisation (09)
- [ ] Motion and reduced motion (10)

## Verbal identity
- [ ] Voice attributes, tone by context, rewrites (11)
- [ ] Writing style, plain and inclusive language, brand name usage (12)

## Accessibility
- [ ] Standard, contrast, colour, type, focus, targets, alt text, media, motion, documents, social, events, testing (13)

## Channels and applications
- [ ] Web and app basics, favicons, email templates and signatures, video, Open Graph (14)
- [ ] Social media: specs, assets, templates, handles, pillars, captions, hashtags, emoji, accessibility, community, crisis, advocacy, influencers, governance (15)
- [ ] Print and stationery (16)
- [ ] Presentations and documents, tagged PDFs (17)
- [ ] Signage, wayfinding, environment, events, vehicles, uniforms, merchandise, packaging (18)
- [ ] Co-branding, sponsorship, sub-brands (19)

## Governance
- [ ] Trademarks, copyright, licences, approvals, owners and contacts, asset library and naming, version history (20)
- [ ] Design tokens exported; asset kit generated; validation gate passed; accessibility audit passed
